# Atividade-UX-UI_DIO



Para essa atividade decidi realizar a criação do zero de uma wireframe de uma página WEB de uma rede social de músicas, onde você acompanha os lançamentos dos artistas seguidos e o que seus amigos estão ouvindo. Utilizado o Figma para criar a atividade.


Organização:
Como primeiro passo decidi criar os átomos. Iniciando pelo ícone representando a logo, os botões, a fonte e o input para o Header, exatamente como demonstrado nas aulas. 
Durante o processo de criação da página alimentei as informações com todos os ícones, tipografia e cores utilizadas.


Cores baseadas em visual atrativo e de fácil leitura para a home page da rede social.
Cor da fonte do conteúdo da página: #E0E0E7
Cor de Fundo e final do Gradiente do Header: #1B1C24
Cor auxiliar usado na caixa de pesquisa, ícone isolado e Gradiente do Header: #FFFCD8
Cor utilizada na transição do Gradiente do Header: #929181


Desafios encontrados:

Tamanho de fonte e de ícones que fiquem visualmente agradáveis.
Padronizei todos os ícones que preenchem a página em 48x48 pixels. Já no Header utilizei dois ícones em 40 para suavização do visual.
As fontes foram selecionadas de acordo com a sua localização na página, utilizadas para compor as informações de cada local ou para chamar atenção a um assunto específico. 

Margens que fiquem visualmente agradáveis.
Durante os testes decidi fixar 96px de cada lado e 48 de cima para baixo, o qual ajudou a ajustar a visualização de cada item.
